Complete Rebranding Solution for Odoo 17.0 Point of Sale

🎯 Features

Replace Odoo Logo
instant-ERP logo appears in the POS navbar instead of Odoo logo
Custom Receipts

Upload your own logos per company

🚀 Quick Start

  1. Open POS: Navigate to Point of Sale → Dashboard → New Session
  2. Verify Branding: Check that instant-ERP logo appears in navbar
  3. Test Receipt: Make a test order and print receipt
  4. Configure: Customize settings in POS Configuration

⚙️ Configuration

POS Settings: Point of Sale → Configuration → Point of Sale → [Your POS]

Look for the instant-ERP Branding section to:

  • Enable/disable instant-ERP branding
  • Set custom receipt header text
  • Set custom receipt footer text

Company Logos: Settings → Companies → [Your Company]

  • Upload custom instant-ERP POS Logo (for navbar)
  • Upload custom instant-ERP Receipt Logo (for receipts)

📋 What Changed?

  • ✅ POS navbar logo replaced with instant-ERP
  • ✅ Receipt header includes instant-ERP logo and custom text
  • ✅ "Powered by Odoo" replaced with "Powered by instant-ERP"
  • ✅ Custom footer text on all receipts
  • ✅ Optional: instant-ERP color scheme (configurable in SCSS)
⚠️ Important: This module uses inheritance only. No core Odoo files were modified. You can safely upgrade Odoo without losing these customizations.

🛠️ Customization

Advanced users can further customize:

  • Brand Colors: Edit static/src/scss/instant_erp_branding.scss
  • Logos: Replace images in static/src/img/
  • Templates: Modify XML files in static/src/app/overrides/

After changes, restart Odoo and clear browser cache.

🆘 Troubleshooting

Logo not showing?

  • Clear browser cache (Ctrl+Shift+R)
  • Close and reopen POS session
  • Check that module is installed (not just downloaded)

Receipt still shows Odoo branding?

  • Update module: ./odoo-bin -u instant_erp_pos_branding -d your_database
  • Clear POS cache in browser
  • Restart Odoo service
